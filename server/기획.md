캔들차트 : 1분봉, 1시간봉, 1일봉, 1주일봉, 1달봉, 1년봉

체결(Match) 서버에서 초당 발생하는 수많은 체결 건(Tick)을 Kafka로 보냅니다.

통계 서버(또는 배치 서버)가 이 Tick 데이터를 모아서 1분마다 하나의 캔들(OHLCV)로 압축(Aggregation)하여 ClickHouse에 저장합니다.

Tip: 1분봉은 데이터양이 꽤 많아집니다 (1종목당 하루 1,440개, 1년 525,600개).

1시간봉, 1일봉, 1주일봉
생성 방식 (Roll-up):

1시간봉: 이미 만들어진 1분봉 60개를 합쳐서 만듭니다.

1일봉: 1시간봉 24개를 합치거나, 1분봉 1440개를 합쳐서 만듭니다.

처리 시점:

미리 배치(Batch)로 계산해서 테이블이나 캐시(Redis)에 넣어두는 것이 좋습니다. (예: 매시 정각에 1시간봉 생성)

ClickHouse의 Materialized View 기능을 사용하면 데이터가 들어올 때 자동으로 이 작업을 백그라운드에서 처리해 주어 매우 편리합니다.

큰 단위: 1달봉, 1년봉
특징: 데이터 개수가 적고 변동 주기가 길기 때문에, 1일봉 데이터를 기반으로 요청 시점에 실시간(On-the-fly) 쿼리를 돌려도 무방할 정도로 부하가 적습니다.

과거 데이터는 통계 서버에서, 실시간 데이터는 웹소켓에서 조립한다

매칭 서버 : 싱글 스레드 기반, LMAX Disruptor Library 
매칭 서버 다운 시 복구 : Kafka Replay
